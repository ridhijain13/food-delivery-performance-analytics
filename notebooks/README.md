# Databricks Notebooks

This folder contains the notebooks used to build the Food Delivery Performance Analytics Pipeline.

## Planned Notebooks
- `01_bronze_ingestion`: Load source delivery data into the Bronze layer.
- `02_silver_cleaning`: Clean timestamps and derive delivery metrics.
- `03_gold_aggregations`: Generate delivery performance summary tables.
- `04_sql_analysis`: Analyze delivery trends using SQL.

The notebooks will be added as they are exported from Databricks.
